# MediNote-AI 老年人安全醫療對話框架

## 專案概述

這是一個專門為老年人設計的安全醫療對話框架，整合了：
- **MediNote-AI**: 智慧對話處理能力
- **John Snow Labs PHI**: 醫療資訊去識別化技術
- **Rocket.Chat**: HIPAA合規的即時通訊平台

## 核心功能

### 🔒 安全與合規
- **HIPAA合規**: 符合醫療資訊隱私法規，對照《HIPAA 2025 合規檢查清單》涵蓋年度風險評估、稽核與事件通報等要求
- **PHI去識別化**: 自動識別並保護個人醫療資訊
- **端到端加密**: 所有對話內容加密傳輸
- **審計追蹤**: 完整的操作記錄和審計功能

### 👴 老年人友善設計
- **WCAG 2.1 AA 導入**：預設字體 16pt 以上、色彩對比 ≥ 4.5:1、互動元件觸控範圍 ≥ 44px，並提供語音輸入的錯誤修正流程。
- **認知負荷管理**：頁面專注單一任務、採用高對比 Sans Serif 字體、提供明確回饋與漸進式導覽，避免一次出現過多資訊。
- **信任建立機制**：關鍵操作皆有確認對話框、可撤銷選項、進度指示與即時求助/客服入口，提升使用信心。
- **多模態支援**：語音輸入/輸出、放大介面、緊急快捷鍵與家庭照護者代管模式，兼顧不同能力需求。

### 🤖 AI智慧功能
- **自然語言處理**: 理解醫療相關對話
- **風險評估**: 自動識別緊急情況
- **用藥提醒**: 智慧用藥時間提醒
- **健康追蹤**: 記錄和分析健康數據

## 安裝與設定

### 環境需求
- Python 3.8+
- Node.js 16+
- Docker (可選)

### 快速開始
```bash
# 安裝依賴
pip install -r requirements.txt

# 設定環境變數
cp config/.env.example config/.env
# 編輯 config/.env 填入必要的API金鑰

# 啟動服務
python src/main.py
```

## 使用情境

### 1. 日常健康諮詢
- 老年人可以詢問健康相關問題
- AI提供安全、準確的醫療資訊
- 所有個人資訊自動去識別化

### 2. 用藥管理
- 設定用藥提醒
- 查詢藥物交互作用
- 記錄用藥情況

### 3. 緊急情況處理
- 快速聯繫家屬或醫護人員
- AI協助判斷緊急程度
- 自動提供急救指導

### 4. 健康數據追蹤
- 記錄血壓、血糖等生命徵象
- 生成健康報告
- 趨勢分析和警告

## 安全特性

- **資料加密**: AES-256加密所有敏感資料
- **存取控制**: 基於角色的權限管理
- **審計日誌**: 完整的操作記錄
- **資料備份**: 自動備份和恢復機制

## 合規與治理藍圖

### HIPAA 2025 重點
- 年度風險評估、政策盤點與人員再訓練，確保行政與程序面持續更新。
- 與所有接觸 PHI 的供應商簽署 BAA，建立事件 72 小時通報流程，包含患者與監管單位通知。
- 實作加密傳輸/靜態資料、防範未授權存取、維護存取稽核與跨區備援。

### AI 治理與倫理框架
- 對照 WHO 六大原則：自主、福祉、透明、責任、包容、公平、永續。
- 建立偏見偵測與緩解流程，針對不同年齡/性別/族群進行公平方測。
- 提供臨床人員可解釋分析（決策摘要、重要特徵），支援人工覆核。

### 緊急應變機制
- 整合生命徵象、行為偵測與一鍵求助，採多層級風險分級與人工覆核。
- 多通道告警（Rocket.Chat、SMS、語音、Email）與照護者通知網絡，追蹤處置狀態。
- 建立季度演練與事件報告，所有紀錄納入 HIPAA 審計日誌。

### 擴展性與效能
- 規劃容器化與 Kubernetes 微服務架構，支援獨立部署/滾動更新。
- 建立標準化 API Gateway（OAuth2/OIDC、Rate Limit、版本管理）與安全測試。
- 監控語音辨識、AI 推理與告警延遲，訂定 SLO/SLI（例如對話 <2 秒、緊急告警 <5 秒）。
