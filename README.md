# MediNote-AI 老年人安全醫療對話框架

## 專案概述

這是一個專門為老年人設計的安全醫療對話框架，整合了：
- **MediNote-AI**: 智慧對話處理能力
- **John Snow Labs PHI**: 醫療資訊去識別化技術
- **Rocket.Chat**: HIPAA合規的即時通訊平台

## 核心功能

### 🔒 安全與合規
- **HIPAA合規**: 符合醫療資訊隱私法規，對照《HIPAA 2025 合規檢查清單》涵蓋年度風險評估、稽核與事件通報等要求
- **PHI去識別化**: 自動識別並保護個人醫療資訊
- **端到端加密**: 所有對話內容加密傳輸
- **審計追蹤**: 完整的操作記錄和審計功能

### 👴 老年人友善設計
- **大字體介面**: 適合視力不佳的老年人
- **簡化操作**: 直觀的使用者介面
- **語音輸入**: 支援語音轉文字功能
- **緊急聯繫**: 一鍵緊急求助功能

### 🤖 AI智慧功能
- **自然語言處理**: 理解醫療相關對話
- **風險評估**: 自動識別緊急情況
- **用藥提醒**: 智慧用藥時間提醒
- **健康追蹤**: 記錄和分析健康數據

## 安裝與設定

### 環境需求
- Python 3.8+
- Node.js 16+
- Docker (可選)

### 快速開始
```bash
# 安裝依賴
pip install -r requirements.txt

# 設定環境變數
cp config/.env.example config/.env
# 編輯 config/.env 填入必要的API金鑰

# 啟動服務
python src/main.py
```

## 使用情境

### 1. 日常健康諮詢
- 老年人可以詢問健康相關問題
- AI提供安全、準確的醫療資訊
- 所有個人資訊自動去識別化

### 2. 用藥管理
- 設定用藥提醒
- 查詢藥物交互作用
- 記錄用藥情況

### 3. 緊急情況處理
- 快速聯繫家屬或醫護人員
- AI協助判斷緊急程度
- 自動提供急救指導

### 4. 健康數據追蹤
- 記錄血壓、血糖等生命徵象
- 生成健康報告
- 趨勢分析和警告

## 安全特性

- **資料加密**: AES-256加密所有敏感資料
- **存取控制**: 基於角色的權限管理
- **審計日誌**: 完整的操作記錄
- **資料備份**: 自動備份和恢復機制
